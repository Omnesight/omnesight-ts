# Security Policy

## Supported Versions

Only the latest active minor release of the Omnesight TypeScript SDK receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

Omnesight takes the security of our infrastructure and clients seriously.

If you discover a vulnerability:

1. **Do not disclose the issue publicly.** Do not open a public GitHub issue.
2. Email **security@omnesight.com** or **solutions@omnesight.com** with details and reproduction steps.
3. Our security team will acknowledge within 24–48 hours and coordinate a coordinated disclosure.
